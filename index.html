VS Code & Codespaces Guide

1. Run Locally in VS Code or GitHub Codespaces
  1. Download index.html below and upload it to your GitHub repo or VS Code folder.
  2. In the project terminal, run npm run dev. The game is served on port 5173.
  3. In Codespaces, open the Ports tab and open forwarded port 5173 in a desktop browser. Keyboard input is required for movement and actions.
2. How to Play Co-Op Multiplayer

Click 👥 Co-Op, enter your name, and select Host Room to get a 4-letter Room Code. Friends can open the same game link, enter your code, and select Join Elevator.
