VS Code, Codespaces & Phone Guide

1. Run Locally in VS Code or GitHub Codespaces
  1. Download index.html below and upload it to your GitHub repo or VS Code folder.
  2. In the terminal, run python3 -m http.server 8000 (or click Go Live in VS Code).
  3. In Codespaces, open the Ports tab, set Port 8000 to Public, and open the URL on your phone!
2. How to Play Co-Op Multiplayer

Click 👥 Co-Op, enter your name, and tap Host Room to get a 4-letter Room Code. Have friends open the same game link on their phone or PC, enter your code, and tap Join Elevator!
